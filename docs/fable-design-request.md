## 依頼文

保護猫チャンネル(YouTubeショート中心)の制作を自動化したい。
今回は**実装ではなく「設計と、後で安いモデルが使い回せる資産づくり」**だけを頼みたい。
このセッションで作ったものを、以後は Sonnet / Opus で回す前提なので、
モデルが変わっても品質が落ちないよう、**判断基準を全部ファイルに書き出す**ことを最優先にしてほしい。

### 前提
- 動画: 30秒〜1分の縦動画(9:16)。素材は**猫の動画が中心**。
- 環境: Windows。音声合成は VOICEVOX、字幕用の文字起こしは Whisper、編集は FFmpeg 中心で考える。
- BGM・効果音は**手元に一つもない**。入手方法から設計に含めてほしい。
- 動画編集経験がない。「YouTubeっぽい編集」の型を知らないので、型から教えてほしい。
- 参考チャンネル: 池崎さとるの猫サブチャンネル、Peco channel、その他バズっている猫チャンネル。
  - 真似してよいのは構成・テンポ・字幕の見せ方などの「型」まで。
  - 他人の映像・音声・BGM・台本の文章は使わない。

### 作ってほしいもの(リポジトリ内にファイルで)
1. **参考チャンネルの分析**(`docs/reference-analysis.md`)
   - なぜ見られているか。冒頭フック、構成の型、テンポ、字幕、音の使い方に分解する。
   - 分からないことは推測と明記する。
2. **編集スタイルの仕様**(`style/shorts-style.md` と、機械が読める `style/shorts-style.json`)
   - 字幕(フォント、色分けルール、サイズ、位置、縦動画の安全領域、強調の出し方)
   - カット、ズーム、無音カットの規則
   - BGMの種類・音量・ダッキング(声の間だけ下げる)の数値
   - 効果音を入れる場所の規則
   - 冒頭1秒のフックと、最後の締め方
3. **BGM・効果音の入手ガイド**(`docs/audio-sourcing.md`)
   - YouTubeで収益化しても使える無料素材の探し方、ライセンスの確認手順、クレジット表記の要否
   - 素材の管理表(`assets/audio-index.csv` のひな形)
4. **台本スキル**(`.claude/skills/cat-script/SKILL.md`)
   - 保護猫チャンネル向けの構成の型、トーン、タイトルとサムネ文言の付け方、ネタ出しの基準
   - 出力形式は台本JSON(セリフ、使う素材、感情、効果音タグ、字幕強調)に固定する
   - 保護猫という題材なので、里親募集・命の扱いで避ける表現の注意点も入れる
5. **パイプライン設計書**(`docs/pipeline-design.md`)
   - 台本JSON → VOICEVOX → Whisper → FFmpeg → mp4 の流れ
   - Windowsでの環境構築手順、フォルダ構成、設定ファイル、失敗時の確認点
   - どこをLLMに任せ、どこをスクリプトで固定するか

### 進め方
- 最初に、不明点があれば質問を最大5つにまとめて聞いてほしい。
- 実装は最小限でよい。ただし**スタイル仕様が妥当か確かめるため、ダミー素材で10秒程度のサンプルを1本**作り、画面で確認できるようにしてほしい。
- 各ファイルの冒頭に「このファイルを読むモデルへの指示」を書く。
  Sonnet / Opus が単体で読んでも作業を再開できる状態にする。
- 判断に迷う点は、選択肢と推奨を1行ずつで示す。長い一覧は不要。

### やらないこと
- 動画の量産。YouTubeへの投稿。他チャンネルの素材のダウンロードや転載。
